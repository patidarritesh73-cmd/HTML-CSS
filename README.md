# HTML-CSS Storefront

A static fashion storefront layout built with HTML and CSS for frontend practice. The page includes navigation, search styling, product categories, and locally stored sample product imagery.

## View locally

Open [`HTML,CSS/index.html`](./HTML,CSS/index.html) in a web browser. Keep the `HTML,CSS` folder and its image folders together so the page's relative asset paths continue to work.

The page links to Google Fonts' Material Symbols stylesheet for its search icon, so that icon requires an internet connection.

## Project files

- `HTML,CSS/index.html` — page markup.
- `HTML,CSS/index.css` — page styles.
- `HTML,CSS/image-shirt/`, `HTML,CSS/image-kurta/`, `HTML,CSS/image-saree/` — page images and icons.
